Mỗi dòng: tên tài liệu | liên kết HTTPS

Đăng thay đổi lên website

  1. Chọn “Lưu vào bản soạn” sau khi thêm hoặc sửa từng văn bản.
  2. Chọn “Tải data.json để đăng”. Giữ nguyên tên tệp data.json.
  3. Mở kho GitHub của trường, chọn Add file → Upload files, tải tệp data.json vừa xuất lên thư mục gốc, sau đó chọn Commit changes.
  4. Chờ GitHub Pages cập nhật, mở trang tra cứu và kiểm tra văn bản mới.

Tệp trên Drive phải nằm trong thư mục được chia sẻ cho nhân viên. Đưa tệp lên Drive không tự thêm tên vào danh mục website.
